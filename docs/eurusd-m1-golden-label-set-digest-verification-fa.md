# تطبیق هش مجموعه‌برچسب Golden برای EURUSD / M1 / REPLAY

این helper هش evidence یک گزارش پذیرفته‌شدهٔ مجموعه‌برچسب Golden را دوباره محاسبه و فقط با هش موردانتظار مقایسه می‌کند. خروجی‌های ممکن `MATCH`، `MISMATCH`، `INVALID_EXPECTED_DIGEST` و برای گزارش ردشده `DIGEST_UNAVAILABLE` هستند.

هیچ گزارش یا برچسبی ذخیره، تغییر یا منتقل نمی‌شود؛ این قابلیت معنا یا کیفیت label را تفسیر نمی‌کند و هرگز candidate، Paper/Demo artifact، OrderIntent، درخواست خارجی یا قابلیت اجرا نمی‌سازد.
